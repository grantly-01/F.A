#  Funding Aggregator

##  Описание проекта

**Funding Aggregator** — это веб-приложение для автоматического сбора, обработки и отображения информации о грантах и финансировании из различных открытых источников.

Система объединяет данные из нескольких платформ, очищает их, структурирует и предоставляет пользователю удобный интерфейс для поиска и анализа актуальных возможностей финансирования.


##  Цель проекта
- Автоматизировать сбор данных о грантах
- Упростить поиск релевантных возможностей финансирования
- Обеспечить централизованный доступ к информации
- Продемонстрировать интеграцию backend, frontend и AI-сервисов


## Архитектура проекта

Проект построен по принципу разделения на независимые модули:

```
backend/        — серверная часть (API, бизнес-логика, обработка данных)
frontend/       — клиентская часть (интерфейс пользователя)
monitoring/     — мониторинг системы (Prometheus)
performance/    — нагрузочное тестирование (Locust)
docker-compose  — оркестрация сервисов
```


## ⚙️ Технологический стек

### Backend:
- Python (FastAPI)
- SQLAlchemy
- Alembic (миграции)
- JWT авторизация
- Интеграция AI (обработка/анализ данных)

### Frontend:
- HTML / CSS / JavaScript (vanilla)
- Работа с API
- Интернационализация (i18n)

### DevOps:
- Docker / Docker Compose
- CI/CD (GitHub Actions)
- Prometheus (мониторинг)


## Основной функционал

### Сбор данных
- Подключение к внешним источникам (grants, euraxess и др.)
- Универсальный scraper
- Расширяемая система источников

### Обработка данных
- Очистка и нормализация информации
- Удаление дубликатов
- Подготовка к хранению

### AI-модуль
- Анализ и фильтрация данных
- Улучшение релевантности результатов

### Авторизация
- Регистрация и вход пользователей
- JWT-токены

### Интерфейс
- Отображение грантов
- Поиск и фильтрация
- Работа с API


##  Структура backend

```
app/
 ├── api/          — эндпоинты API
 ├── models/       — модели базы данных
 ├── schemas/      — Pydantic-схемы
 ├── services/     — бизнес-логика
 ├── collector/    — сбор данных (scrapers)
 ├── processor/    — обработка данных
 ├── core/         — настройки, безопасность, логирование
```

## ▶️ Запуск проекта

### 1. Клонирование репозитория

```bash
git clone <repo_url>
cd funding-aggregator
```

### 2. Запуск через Docker

```bash
docker-compose up --build
```

### 3. Доступ к сервисам

* Backend API: [http://localhost:8000](http://localhost:8000)
* Frontend: [http://localhost:3000](http://localhost:3000) (или через index.html)
* Prometheus: [http://localhost:9090](http://localhost:9090)


## Тестирование

### Backend тесты:

```bash
pytest
```

### Нагрузочное тестирование:

```bash
locust -f performance/locustfile.py
```

## Мониторинг
Используется Prometheus для:
- сбора метрик
- отслеживания состояния системы
- анализа производительности

## CI/CD
Настроен через GitHub Actions:
- автоматическая проверка кода
- запуск тестов
- контроль качества
